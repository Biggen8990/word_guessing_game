Help / About

Welcome to the Word Guessing Game web app!

  • Choose "Play Game" from the main menu to start guessing words.
  • Type a guess, or 'give up' to quit the round early and reveal the answer.
  • Type 'y' or 'n' for yes/no prompts.
  • Switch or import a word list using the menu if your tier allows.
  • Check your leaderboard, stats, or progress from the menu.
  • Tier: {{ user_tier.title() }} — see the README for feature details.

FAQ

  • How do I change difficulty? — Select easy/hard before each round.
  • How do I switch players in multiplayer? — Use 'Swap roles' after each round.
  • Where are my stats? — Check the leaderboard or user progress (admin).
  • Can I use my own word list? — Yes, if your tier unlocks import; see import option in menu.
